# 모치모치 일본어 (もちもち にほんご)

일본에서 **생활하고 일하기 위한** 일본어를 듀오링고처럼 연습하는 웹앱입니다.
설치·빌드·서버 없이 `index.html` 파일 하나만 열면 바로 동작합니다.

## 왜 만들었나

듀오링고는 하트(에너지)가 떨어지면 더 못 하고, 배우는 문장이 실생활과 거리가 있습니다.
이 앱은 그 두 가지를 정반대로 잡았습니다.

- **에너지·하트 없음** — 틀려도 제한 없이 계속 학습합니다. 틀린 문장은 큐 뒤로 다시 들어옵니다.
- **실전 문장만** — 편의점, 전철, 병원, 구청, 부동산, 회사 인사·보고, 전화·메일, 회식, 면접, 트러블 대응, 회의, 비즈니스 메일, 커리어까지 17개 상황 136문장.
- **N5 → N2 6단계** — 모든 문장에 레벨 태그가 붙고, 학습 경로가 단계별로 나뉘어 있습니다.
- **후리가나(ruby)** — 한자 위에 히라가나·가타카나 읽는 법이 올라갑니다. 설정에서 끌 수 있어요.
- **아는 건 건너뛰기** — 실력 테스트로 시작 단계를 정하고, 쉬운 단계·유닛은 시험 한 번으로 통째로 넘어갑니다.
- **음성 재생** — 브라우저 내장 음성합성(`SpeechSynthesis`, `ja-JP`)으로 모든 문장을 듣고, 「천천히」로 더 느리게 들을 수 있습니다.
- **오리지널 캐릭터 4종** — 모치·네코·우사·토리. 전부 인라인 SVG로 그려서 정답/오답에 따라 표정이 바뀝니다.

## 기능

| 탭 | 하는 일 |
|---|---|
| 학습 | 6단계 34레슨 경로. 새 문장 소개 → 뜻 고르기 → 일본어 고르기 → 듣고 고르기 → 단어 배열 → 빈칸 채우기 → (선택) 말하기. 단계·유닛 건너뛰기 시험 포함 |
| 문장집 | 136문장 전체 검색·즐겨찾기, N5/N4/N3/N2/관용구 레벨 필터. 한국어/일본어/로마자 모두 검색됨 |
| 복습 | 틀렸던 문장만 모아 집중 복습, 배운 문장 랜덤 복습, 단계별 진도 |
| 내 정보 | XP·연속 학습일·완료 레슨, 후리가나/로마자/자동재생/말하기/잠금해제/음성 속도/일일 목표/테마 설정 |

## 난이도 (N5 → N2, 6단계)

| 단계 | 유닛 | 레벨 |
|---|---|---|
| 1단계 · 입문 | 첫 만남 / 편의점 / 전철 / 식당 | N5 |
| 2단계 · 정착 | 집 구하기·관공서 / 병원 | N5–N4 |
| 3단계 · 출근 | 회사 인사 / 보고·부탁 / 전화 | N4 |
| 4단계 · 관계 | 잡담·회식 / 면접 / 반말 | N4 |
| 5단계 · 실전 | 경어 제대로 / 트러블 대응 / 회의 | N3 |
| 6단계 · 비즈니스 | 비즈니스 메일 / 커리어·면접 심화 | N2 |

문장에 쓰인 **문법**을 기준으로 레벨을 붙였습니다.

- **N5** `〜です/ます` `〜をください` `〜たいです` `〜てもいいですか` `〜ています` `〜ましょう`
- **N4** 가능형(`払えます`) `〜てもらえますか` `〜てしまう` `〜てから` `までに` `〜んです` `〜こと` `ます형＋方`
- **N3** 겸양·존경어(`いたします` `いらっしゃる` `おります`) `〜そうです` `〜んですが` `〜させてください` `〜ないようにする` `〜かもしれません`
- **N2** `〜につきまして` `〜た上で` `ございましたら` `申し上げます` + 비즈니스 문서 어휘(`ご査収` `何卒` `標題の件`)
- **관용구** `お疲れ様です` `お世話になっております`처럼 문법을 따지지 않고 통째로 외우는 고정 표현

3단계까지는 N4로 말하고, 5·6단계에서 같은 상황을 경어로 다시 배웁니다.
예를 들어 3단계의 `あとで電話します`는 5단계에서 `折り返しお電話いたします`로,
`確認してから連絡します`는 `ご確認いただけますでしょうか`로 올라갑니다.

JLPT는 레벨별 어휘·한자 목록을 공식 공개하지 않으므로, 문법 범위를 레벨 판정 기준으로 삼았습니다.
`在留カード`, `保険証`, `家賃`처럼 레벨을 넘지만 그 일을 처리하려면 반드시 필요한 명사는 그대로 두었습니다.

## 후리가나 (ruby)

한자 위 읽는 법은 표준 `<ruby>` / `<rt>` 요소로 렌더링합니다(Chrome·Firefox·Safari·Edge 지원).
후리가나 데이터를 따로 손으로 적지 않고, `jp`(표기)와 `kana`(전체 읽기)를 **자동 정렬**해서 만듭니다.

- 가나·문장부호는 앵커로 두고, 그 사이의 한자·영문 덩어리에 읽기를 배분합니다
- `別々` `少々`처럼 반복 기호(々)는 한자 쪽에 붙여 `べつべつ`로 읽습니다
- `AI開発` → `AI[エーアイ]開発[かいはつ]`처럼 영문 약어도 읽기가 붙습니다
- 자동 정렬이 너무 넓게 묶는 문장만 `rb` 필드로 직접 지정합니다 (`この{薬|くすり}は{一日|いちにち}…`)

136문장 전부 정렬에 성공하며, 실패 시에는 가나 한 줄로 안전하게 폴백합니다.

## 건너뛰기 (아는 단계는 넘어가기)

세 가지 방법이 있고, 셋 다 **떨어져도 잃는 것이 없습니다.** 횟수 제한도 없어요.

| | 어디서 | 문제 수 | 통과하면 |
|---|---|---|---|
| **실력 테스트** | 학습 탭 상단 카드 / 내 정보 → 건너뛰기 | 12문제 (N5·N4·N3·N2 각 3문제) | 맞힌 수준까지의 단계를 전부 완료 처리 |
| **단계 건너뛰기** | 각 단계 헤더 아래 버튼 | 그 단계에서 뽑은 최대 12문제 | 그 단계의 모든 레슨 완료 |
| **유닛 건너뛰기** | 유닛 배너의 `⏭ 건너뛰기` | 그 유닛 8문제 | 그 유닛의 레슨 2개 완료 |

- 통과 기준은 **정확도 80%** 입니다 (실력 테스트는 레벨당 3문제 중 2문제 이상).
- 시험에는 **새 문장 소개 카드가 나오지 않고**, 4지선다 뜻 고르기도 빠집니다.
  일본어를 직접 골라내거나(듣고 고르기·한국어→일본어), 단어를 배열하거나, 빈칸을 채워야 해요.
- 일반 레슨과 달리 **틀려도 문제가 다시 나오지 않습니다.** 시험이니까요.
- 틀린 문장은 그대로 복습 탭에 쌓이므로, 떨어져도 약점 목록은 남습니다.
- 건너뛴 레슨도 언제든 다시 눌러 처음부터 풀 수 있습니다.

실력 테스트 배치 기준: N5 통과 → 1단계, N4 통과 → 1~4단계, N3 통과 → 1~5단계, N2 통과 → 전 단계.

## 사용법

```bash
# 그냥 파일을 열기
open index.html          # macOS
start index.html         # Windows

# 또는 로컬 서버로
npx serve .
```

학습 기록은 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.

## 음성이 안 들릴 때

음성은 브라우저·OS에 설치된 일본어 음성을 사용합니다(Chrome 33+, Edge, Safari, Firefox 49+ 지원).
「내 정보 → 음성」에서 찾은 일본어 음성 목록을 확인하고 원하는 목소리를 고를 수 있습니다.
목록이 비어 있으면 OS 설정에서 일본어 음성을 추가해 주세요.

- Windows: 설정 → 시간 및 언어 → 언어 → 일본어 추가
- macOS/iOS: 설정 → 손쉬운 사용 → 음성 콘텐츠 → 음성 → 일본어
- Android: 설정 → 텍스트 음성 변환 → 언어 데이터 설치

「말하기」 문제의 마이크 인식은 `SpeechRecognition`을 지원하는 브라우저(Chrome/Edge)에서만 자동 채점되고,
그 외 브라우저에서는 직접 따라 말한 뒤 버튼을 누르는 방식으로 동작합니다.

## 문장 추가하기

`index.html` 안의 `UNITS` 배열에 항목을 넣으면 레슨·문제·문장집에 자동 반영됩니다.

```js
{ lv:'N5',                           // 'N5'|'N4'|'N3'|'N2'|'慣'(통암기 관용구)
  jp:'お会計お願いします。',          // 표시할 일본어
  kana:'おかいけいおねがいします。',  // 읽는 법
  ro:'O-kaikei onegai shimasu.',     // 로마자
  ko:'계산 부탁드려요.',              // 뜻
  tip:'「お勘定」도 같은 뜻이에요.',   // 실제로 언제 쓰는지
  chunks:['お会計','お願いします'],   // 단어 배열/빈칸 문제용 조각
  rb:'お{会計|かいけい}お{願|ねが}いします。' }  // (선택) 후리가나 직접 지정
```

한 유닛의 문장 4개가 자동으로 한 레슨이 됩니다.
