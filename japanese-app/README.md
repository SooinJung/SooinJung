# 모치모치 일본어 (もちもち にほんご)

일본에서 **생활하고 일하기 위한** 일본어를 듀오링고처럼 연습하는 웹앱입니다.
설치·빌드·서버 없이 `index.html` 파일 하나만 열면 바로 동작합니다.

## 왜 만들었나

듀오링고는 하트(에너지)가 떨어지면 더 못 하고, 배우는 문장이 실생활과 거리가 있습니다.
이 앱은 그 두 가지를 정반대로 잡았습니다.

- **에너지·하트 없음** — 틀려도 제한 없이 계속 학습합니다. 틀린 문장은 큐 뒤로 다시 들어옵니다.
- **실전 문장만** — 편의점, 전철, 병원, 구청, 부동산, 회사 인사·보고, 전화·메일, 회식, 면접, 친구와의 반말까지 12개 상황 96문장.
- **난이도는 JLPT N5–N4 고정** — 모든 문장이 N5(63) / N4(21) / 통암기 관용구(12)로 태그되어 있고, 문장집에서 레벨별로 걸러 볼 수 있습니다.
- **음성 재생** — 브라우저 내장 음성합성(`SpeechSynthesis`, `ja-JP`)으로 모든 문장을 듣고, 「천천히」로 더 느리게 들을 수 있습니다.
- **오리지널 캐릭터 4종** — 모치·네코·우사·토리. 전부 인라인 SVG로 그려서 정답/오답에 따라 표정이 바뀝니다.

## 기능

| 탭 | 하는 일 |
|---|---|
| 학습 | 유닛별 레슨 경로(24레슨). 새 문장 소개 → 뜻 고르기 → 일본어 고르기 → 듣고 고르기 → 단어 배열 → 빈칸 채우기 → (선택) 말하기 |
| 문장집 | 96문장 전체 검색·즐겨찾기, N5/N4/관용구 레벨 필터. 한국어/일본어/로마자 모두 검색됨 |
| 복습 | 틀렸던 문장만 모아 집중 복습, 배운 문장 랜덤 복습 |
| 내 정보 | XP·연속 학습일·완료 레슨, 후리가나/로마자/자동재생/말하기/잠금해제/음성 속도/일일 목표/테마 설정 |

## 난이도 기준 (N5–N4)

문장에 쓰인 **문법**이 N5 또는 N4 범위 안에 들어오도록 맞췄습니다.

- **N5** — `〜です/ます`, `〜をください`, `〜たいです`, `〜てもいいですか`, `〜ています`, `〜ましょう`
- **N4** — 가능형(`払えます`), `〜てもらえますか`, `〜てしまう`, `〜てから`, `までに`, `〜んです`, `〜こと`, `동사ます형＋方`
- **관용구** — `お疲れ様です`, `お世話になっております`, `承知しました`처럼 문법은 N3 이상이지만 일본 회사에서 매일 듣고 쓰는 고정 표현. 분해하지 않고 통째로 외우는 항목으로 따로 표시했습니다.

겸양어·존경어 완성형(`ご確認いただけますでしょうか`, `伺えますか`, `折り返しお電話いたします` 등)은 문장 본문에서 빼고,
해당 문장의 **팁에 "더 정중하게는 〜"** 로 남겨 두었습니다. 지금은 N4로 말하고, 상대가 쓰는 정중형은 알아듣는 구조입니다.

JLPT는 레벨별 어휘·한자 목록을 공식 공개하지 않으므로, 문법 범위는 통용되는 N4 문법 리스트를 기준으로 삼았습니다.
`在留カード`, `保険証`, `家賃`, `乗り換え`처럼 레벨을 넘지만 그 일을 처리하려면 반드시 필요한 명사는 그대로 두었습니다.

## 사용법

```bash
# 그냥 파일을 열기
open index.html          # macOS
start index.html         # Windows

# 또는 로컬 서버로
npx serve .
```

학습 기록은 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.

## 음성이 안 들릴 때

음성은 브라우저·OS에 설치된 일본어 음성을 사용합니다(Chrome 33+, Edge, Safari, Firefox 49+ 지원).
「내 정보 → 음성」에서 찾은 일본어 음성 목록을 확인하고 원하는 목소리를 고를 수 있습니다.
목록이 비어 있으면 OS 설정에서 일본어 음성을 추가해 주세요.

- Windows: 설정 → 시간 및 언어 → 언어 → 일본어 추가
- macOS/iOS: 설정 → 손쉬운 사용 → 음성 콘텐츠 → 음성 → 일본어
- Android: 설정 → 텍스트 음성 변환 → 언어 데이터 설치

「말하기」 문제의 마이크 인식은 `SpeechRecognition`을 지원하는 브라우저(Chrome/Edge)에서만 자동 채점되고,
그 외 브라우저에서는 직접 따라 말한 뒤 버튼을 누르는 방식으로 동작합니다.

## 문장 추가하기

`index.html` 안의 `UNITS` 배열에 항목을 넣으면 레슨·문제·문장집에 자동 반영됩니다.

```js
{ lv:'N5',                           // 'N5' | 'N4' | '慣'(통암기 관용구)
  jp:'お会計お願いします。',          // 표시할 일본어
  kana:'おかいけいおねがいします。',  // 읽는 법
  ro:'O-kaikei onegai shimasu.',     // 로마자
  ko:'계산 부탁드려요.',              // 뜻
  tip:'「お勘定」도 같은 뜻이에요.',   // 실제로 언제 쓰는지
  chunks:['お会計','お願いします'] }  // 단어 배열/빈칸 문제용 조각
```

한 유닛의 문장 4개가 자동으로 한 레슨이 됩니다.
